# Piston Pit — Brand Identity Moodboard

[Open the moodboard](https://rahannizamoppoid-stack.github.io/piston-pit-moodboard/) · [View live results](https://rahannizamoppoid-stack.github.io/piston-pit-moodboard/results.html)

A 16-slide brand direction deck with competitor analysis, a qualitative competitor color wheel, brand strategy and six founder-selected concept directions.

## Concept likes

Use **I like this one** on any concept page (slides 8–13). You can like several concepts and click again to remove a like. No account is required. Each browser can have one active like per concept.

The Results link shows shared anonymous totals and the number of browsers with at least one active like. It refreshes every 15 seconds and includes a **Download CSV** button. Results are public. Percentages can exceed 100% in total because multiple concepts can be liked.

The deck is hosted on GitHub Pages. Votes are stored centrally by the Piston Pit voting Site; they require an internet connection. A random browser token remembers choices. Clearing browser data or using another device allows another response, so this is an informal brand preference survey rather than a verified one-person ballot. No names or email addresses are collected by the voting application.

The separate discussion-notes form on slide 15 saves notes on the viewer's device; it does not send those notes to the owner. Use Download notes to share them separately.

## Presentation

Navigate with the arrow keys or slide menu. Overview displays all pages; Present opens presentation mode. Print / PDF prints the 16 slides.

## Reference context

The six visual directions and logo treatments are proposals. The selected generated images illustrate possible applications, not existing products or facilities. The competitor wheel is an approximate visual comparison, not measured market-share research. Brand and competitor references remain the property of their respective owners.
